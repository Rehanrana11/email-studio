# Rise & Crumb — Email Studio

Email studio for **Rise & Crumb**, a small made-up bakery, run with the `studio-kit` plugin. This is practice
only: every lead is invented, every address ends in `@example.com`, and sends go only to the local Resend emulator.
Brand rules live in this repo (`brand/voice.md`, `studio.config.json`, `.claude/rules/emails.md`); the plugin
brings the tools (linter, send guard, personalize skill, email-reviewer subagent). Ask the owner before deleting
anything.
