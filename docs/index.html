Claude Code · Email marketing lab

An email studio where emailing a real person is the hard part.

Plan a launch, write on-brand copy, personalize it per audience, and send it only to a local test inbox. Every check is automated, and every check is tested to prove it can fail.

What's in the studio

A made-up spice shop, Clove & Copper, launching a made-up monthly box, The Spice Circle.

🎙️ Brand voice

A human guide plus a machine-readable config, kept in sync by a test.

🗺️ Launch plan

Ten-section plan and a four-email sequence with A/B sample sizes worked out first.

👥 24 fake leads

Three audiences, all on @example.com, validated on every run.

✉️ 16 emails

Four base emails and twelve personalized versions with a CAN-SPAM-style footer.

🛡️ Send guard

Default-deny hook on MCP, Bash, PowerShell and WebFetch. Test inbox and your own address only.

📏 Linter

Objective rules from config: CTA count, claims, urgency, prices, deadline, UTMs, footer.

⚖️ LLM judge

Judgement calls the linter can't make, with schema-validated output.

🎯 Calibration

Golden set with precision, recall, Cohen's κ and 95% intervals.

The workflow

Brand → plan → leads → copy → personalization → checks → practice send.

1
Voice and rules

brand/voice.md for people, studio.config.json for the linter.

2
Plan and sequence

Drafted with Anthropic's marketing plugin, then edited by hand.

3
Write and personalize

The personalize skill runs as a fork, writes 12 versions, and lints its own output.

4
Check

Linter on every push; LLM judge on PRs that touch copy. Tool errors exit 2, never 0.

5
Practice send

Email 01 per group to delivered@resend.dev on a local emulator, then the inbox is verified.

The send guard, by example

Every row is a test in tests/send-guard.test.mjs.

Tool callResultWhy
send-email to delivered@resend.devallowTest inbox
send-email to a lead on @example.comblockNot an allowed recipient
send-email to x@resend.dev.evil.comblockExact domain match only
send-batch-emails to the test inboxblockMCP is default-deny
send-broadcastblockDenied in settings and in the hook
list-emailsallowRead-only
Bash: curl https://api.resend.com/emailsblockReal provider host
Bash: python -c "import smtplib…"blockDirect SMTP
Malformed hook inputblockFails closed

A hook is a guardrail, not a sandbox. The layer that makes a real send impossible is that no real provider key exists in the studio: .mcp.json hard-codes a dummy key and a localhost URL.

Linter vs judge

Cheap, deterministic checks first. The model only gets the judgement calls.

📏 Linter

Length, emoji, ALL CAPS, Re:, one CTA, no extra links, banned phrases, token fallbacks, prices, deadline, UTMs, footer, lead data. 31 mutation tests break one rule each and check it's caught.

⚖️ Judge

Implied health claims ("good for your gut"), soft scarcity ("spots are going quickly"), guilt, a second CTA in prose, invented offer terms. Measured against a golden set before it's trusted as a gate.
